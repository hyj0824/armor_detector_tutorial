检出率 = 有目标的帧 / 总帧；命中率 = hit / resolved（仿真统计）。
命中/s = hit / 运行秒数 —— 同时体现精度和吞吐，**这个才是主指标**。
跟踪误差 = 云台实际指向 vs 理想弹道解 的中位数（度，剔除开局接管瞬态，越小越好）。
落点cm = 命中落点到装甲板中心的板面内距离（只统计命中发，越小越准）。
换板/s = 云台当前指向最近的那块板的 id 变化率。旋转靶上主要由几何决定，**不能**当成'我们的跟踪器跳板了'。
除检出率/检测ms 外，全部指标来自仿真 state.json，不受被测程序打印影响。
仿真/墙钟 = 这一轮仿真时间走了多少秒 / 真实时间多少秒。理想 1.00；明显小于 1 说明机器跑不动（仿真掉步），这一轮的命中/s 会偏低，不能跨轮比较。
