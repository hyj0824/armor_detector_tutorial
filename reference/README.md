# 参考实现（讲师用）

这个目录**默认不编译**，也不该发给学生：

```bash
cmake -S . -B build -DBUILD_REFERENCE=ON
cmake --build build -j
ARMOR_BIN=build/armor_aim_ref bench/run.sh spin 8
```

它的唯一用途是回答"这件事到底能做到多好"——给学生一个参照点，
知道自己是卡住了还是还差得远，而不是凭感觉判断。
标定结果见 `docs/stages.md`。

## 它做了什么

| 阶段 | 做法 | 文件 |
|---|---|---|
| S1 距离 | 两灯条端点做平面 PnP，小/大装甲两种间距取重投影误差小的 | `solver_ref.cpp` |
| S1 弹道 | 飞行时间与抬升角互相迭代 5 次 | `solver_ref.cpp` |
| S2 关联 | 世界系三维位置 + 距离门限；滑动最小二乘给位置和速度 | `pipeline_ref.cpp` |
| S3 提前量 | 用拟合速度外推到"弹丸到达时" | `pipeline_ref.cpp` |
| S3 前馈 | 把目标角速度填进 `Command::yaw_vel`，仿真的伺服会用到 | `pipeline_ref.cpp` |
| S4 生命周期 | 观测超过 250 ms 没更新就停控停火 | `pipeline_ref.cpp` |

## 它做不到什么（这些是刻意留着的）

- **复合运动（`combined`）只有 0.38 命中/秒**，和基线打平。滑动线性拟合对
  摆线轨迹无效，正解是估计"整车旋转 + 平移"而不是单块板。
- **7 m 完全没有目标**，因为检测在 6 m 就断了。参考实现没有改检测。
- **没有线程、没有延迟补偿、没有开火时机优化**。

也就是说：这份参考实现代表"一个认真做了两周的学生大概能到的高度"，
而不是"这个问题的上限"。
